\subsection*{Chapter 1}
\answer{1.1}{Hypothesis: two angles are complementary. Conclusion: their measures add to $90\degs$.}
\answer{1.2}{Converse: if two angles are congruent, they are vertical (false). Inverse: if two angles are not vertical, they are not congruent (false). Contrapositive: if two angles are not congruent, they are not vertical (true). The original is true.}
\answer{1.3}{$6$ (or $2$, $10$, any number divisible by 2 but not 4)}
\answer{1.4}{$AC = AB + BC$ and $BD = BC + CD$ by segment addition; $AB = CD$ is given; substitute to get $AC = BD$.}
\answer{1.5}{$\angle 1 + \angle 2 = 180\degs$ and $\angle 2 + \angle 3 = 180\degs$; so $\angle 1 + \angle 2 = \angle 2 + \angle 3$; subtract $\angle 2$.}
\answer{1.6}{An angle is a right angle if and only if it measures $90\degs$. If an angle is right then it measures $90\degs$; if an angle measures $90\degs$ then it is right.}
\answer{1.7}{True. Converse false: $x = 4$.}
\answer{1.8}{If a triangle is not isosceles, then it does not have two congruent angles. A statement and its contrapositive are equivalent.}
\answer{1.9}{If $n \ge 0$ then the call returns $n!$. Contrapositive: if the call did not return $n!$, then $n < 0$. A wrong value means the precondition was violated (assuming the function is correct).}
\answer{1.10}{$ABCD$ is a rectangle. No; that would be affirming the consequent (assuming the converse).}
